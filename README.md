# Myntra-clone
This is a Myntra Clone web application built using the MERN stack, designed to replicate the core features of the popular fashion e-commerce platform Myntra.
It provides a seamless shopping experience with product listings, cart management, and responsive design.

## Features
 Browse Products – Clothing, accessories, and more
 Add to Cart – Manage selected products in a shopping cart
 Search & Filter – Easily find products
 User Authentication – Signup/Login (JWT-based if implemented)
 Responsive UI – Works on desktop and mobile devices

 ## Tech Stack
>>Frontend
  React.js
  HTML5, CSS3, JavaScript (ES6
  Redux / Context API (if used)
>>Backend
  Node.js
  Express.js
  Databas
  MongoDB (Mongoose ORM)
  Other Tools
  JWT / Bcrypt for authentication (if implemented)
  Axios for API calls
